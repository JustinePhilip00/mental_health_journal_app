🛠 <b> Technologies Used </b>
<br>

Python — core programming language. <br>
Streamlit — for building an interactive, user-friendly web app. <br>
Pandas — for handling and processing mood journal data. <br>
Matplotlib (via Streamlit) — for plotting mood trends. <br>
Virtual Environment (venv) — to manage dependencies. <br>

💡 <b> Description </b>
<br> 

This is a Mental Health Journal Web App that lets you log your mood throughout the day, reflect on your thoughts, and see how your mood changes over time.
It’s built with Streamlit, so it runs right in your browser — no complicated setup or heavy frameworks. The idea is to make tracking your mental well-being as simple and approachable as jotting something down in a notebook, but with the bonus of clear visual insights.

You can: <br>
✅ Add entries with your mood (Positive, Neutral, Negative) and notes. <br>
✅ View your mood trends on a clean, interactive graph.<br>
✅ See patterns in your mental state to help with self-reflection.<br> 

🚀 Instructions to Run
1) Clone the repository `` git clone https://github.com/JustinePhilip00/mental_health_journal_app.git ``
2) Create & activate a virtual environment <br> 
note:- In PowerShell (temporary bypass to allow activation) (Type in these 3 commands) <br> 
``Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass `` <br> 
``python -m venv venv`` <br> 
`` .\venv\Scripts\activate `` <br>
3) Install dependencies 
`` pip install -r requirements.txt ``
4) Run the app
`` streamlit run app.py ``
